# Comprobador de diagramas ER

Comprobador de diagramas Entidad-Relación en notación BigER para la asignatura Bases de Datos de la Universidad de Extremadura, basado en [sql-snippets](https://github.com/rre-uex/sql-snippets).

Incluye [pako](https://github.com/nodeca/pako) 2.1.0 (licencia MIT y Zlib).
